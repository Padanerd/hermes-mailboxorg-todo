# Security

Do not report vulnerabilities containing exploitable details or private data
in public issues. Use this repository's private vulnerability reporting feature
under Security → Report a vulnerability.

Never send passwords, tokens, `.env` files, private task exports, real collection
URLs or unredacted logs. Supply a synthetic reproduction and the affected code
path. There is currently no guaranteed response time or supported-version SLA.

Use a dedicated, revocable CalDAV app password. If a credential is exposed,
revoke it in Mailbox.org and replace it locally through masked input.
