# Contributing

This pilot is currently maintained through **Issues only**. Pull requests are
disabled. Forks and modifications are welcome under the MIT license.

Please open an issue before proposing a significant feature. Include a minimal
synthetic example, expected behavior, observed behavior and relevant versions.
Do not attach private logs, task exports, `.env` files, DAV collection URLs,
Signal phone numbers, tokens or app passwords. Describe a reproduction using
test accounts and invented task text instead.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md).
